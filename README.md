# IITK Skating Club 🛼

Welcome to the official repository for the **IITK Skating Club (Academic Year 2026–27)** website. This static website serves as the central hub for our vibrant skating community, providing information about our programs, events, and culture.

## About the Project
The Skating Club at IIT Kanpur exists to make skating accessible to every student, from beginners to competitive athletes. We cover multiple disciplines:
- **Speed Skating**
- **Roller Hockey**
- **Skateboarding**
- **Waveboarding**
 
This website is a beautifully designed, fully responsive static single-page application built with modern web aesthetics in mind, featuring:
- Glassmorphism UI elements
- Micro-animations and hover effects
- A dynamic, auto-scrolling gallery marquee
- Responsive design tailored for both desktop and mobile devices 

## Development
The project is built entirely with core web technologies for maximum performance and easy hosting:
- **HTML5**
- **Vanilla CSS**
- **Vanilla JavaScript** (inline/scripts where applicable)

### Running Locally
To run the project locally, you don't need any complex build tools. You can simply:
1. Clone this repository.
2. Open `index.html` in any modern web browser.
3. Alternatively, for a better development experience (to prevent local CORS issues with some assets), serve the directory with a local HTTP server. For example:
   ```bash
   # Using Python
   python -m http.server
   
   # Using Node.js
   npx serve .
   ```

## Deployment
This project is configured as a standard static site, making it perfectly compatible with free deployment platforms like **GitHub Pages**, **Vercel**, **Netlify**, or **Render**. 
- All image assets are correctly tracked in the Git repository.
- File paths are configured explicitly (`./assets/...` and `./favicon/...`) to ensure compatibility regardless of whether it is hosted on a root domain or a subdirectory.
